# CORE LogiTrack — Landing Page

Landing page institucional do **CORE LogiTrack**, plataforma WMS SaaS para operações logísticas e distribuição de autopeças.

## Deploy

Este projeto é deployado automaticamente no Vercel.

- **Domínio principal:** `corelogitrack.com.br`
- **WWW:** `www.corelogitrack.com.br`

## Estrutura

```
public/
├── index.html    # Landing page completa
├── logo.png      # Logo CORE (ícone)
└── izaias.jpg    # Foto do consultor
```

## Configuração no Vercel

1. Conectar este repositório ao projeto `corelogitrack-landing` no Vercel
2. Output Directory: `public`
3. Adicionar domínios: `corelogitrack.com.br` e `www.corelogitrack.com.br`
